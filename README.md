Для работы сервера нужны библиотеки:
```bash
python -m venv .venv
./.venv/Scripts/activate.bat # активация venv
python -m pip install -r requirements
```

Запуск сервера осуществляется из каталога
```bash
./server/src
```
так как путь к базе данных относительный
